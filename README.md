# FirmCorrLab 企业相关性分析与可视化工具

FirmCorrLab 是一个基于 Python 和 PyQt5 的桌面分析工具，围绕企业价格数据提供企业、行业和区域三个层面的相关性分析。程序集成对数收益率计算、市场与分组因子剔除、滑动窗口分析、子集筛选、行业与区域加权矩阵构建，以及可自定义配色的热力图生成，支持将分析结果导出为 Excel，将热力图保存为图片或 PDF。

适合需要通过图形界面探索企业联动关系、比较行业与区域关联程度，以及整理研究图表的用户。

当前入口文件为 `correlation_analysis_integrated_V1.5.py`。以下操作说明对应该文件的现有界面与计算行为。

## 主要功能

| 模块 | 功能 | 输出 |
| --- | --- | --- |
| 主计算 | 导入企业价格数据，计算对数收益率，可剔除市场、行业、区域因子；生成企业矩阵及行业、区域聚合矩阵 | 相关性热力图、滑动平均相关性曲线、年度统计、Excel 工作簿 |
| 子集相关性分析 | 按行业和区域筛选企业，选择 Pearson、Spearman 或 Kendall 方法 | 子集矩阵、统计摘要、可选的滑动曲线、Excel 工作簿 |
| 违约相关性矩阵计算器 | 按行业和区域相关矩阵、企业分类信息及权重，构建企业间的加权关联矩阵 | 矩阵热力图、Excel 文件 |
| 相关性矩阵热力图生成器 | 导入矩阵，自定义负值、零值和正值配色、标题、数值标注及颜色过渡 | 300 DPI 的 PNG、JPEG 或 PDF |

“违约相关性矩阵计算器”沿用现有界面名称，其具体加权公式与结果含义见下文。

## 安装与启动

需要安装 Python 3，并具备可显示桌面窗口的运行环境。依赖包括 NumPy、pandas、PyQt5、Matplotlib、seaborn、openpyxl 和 SciPy；读取旧版 `.xls` 文件还需要 xlrd。

下面以 Windows PowerShell 为例。在存放程序文件的文件夹中打开终端，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy pandas PyQt5 matplotlib seaborn openpyxl scipy
.\.venv\Scripts\python.exe correlation_analysis_integrated_V1.5.py
```

如果需要读取 `.xls` 文件，再执行：

```powershell
.\.venv\Scripts\python.exe -m pip install xlrd
```

启动后，窗口顶部显示四个功能页签。程序会尝试使用系统中的中文字体；如果图中的中文显示为方框，请安装微软雅黑、黑体等支持中文的字体后重新启动。

## 准备输入数据

### 主计算用价格表

价格表采用“每行一家企业、每列一个日期”的布局，前三列依次为企业名称、行业、区域，其余列为价格。

| 企业名称 | 行业 | 区域 | 2025-01-02 | 2025-01-03 | 2025-01-06 | 2025-01-07 |
| --- | --- | --- | --- | --- | --- | --- |
| 企业A | 制造业 | 华东 | 10.00 | 10.20 | 10.10 | 10.35 |
| 企业B | 制造业 | 华北 | 15.00 | 14.80 | 15.10 | 15.05 |
| 企业C | 信息技术 | 华东 | 20.00 | 20.60 | 20.20 | 20.80 |

上表仅展示格式，不足以运行默认的 60 期滑动窗口。准备数据时请满足以下条件：

- 至少包含两家企业，企业名称使用唯一的文本名称；行业和区域分类完整、命名一致。
- 前三列必须保持上述顺序。程序按位置识别并重命名前三列，不根据原列名判断含义。
- 日期列使用 Excel 日期或 `YYYY-MM-DD` 文本，并从左到右按时间先后排列。程序按原列顺序计算相邻期收益率，不自动排序。
- 价格填写数值，且应为有限的正数；价格区域不要混入备注、百分比文本或其他非数值内容。
- 默认窗口为 60 个收益率观测，完整价格数据至少需要 61 个时间点。企业价格长期不变，或有效样本不足时，相关系数可能为空。
- 将数据放在工作簿的第一张工作表，第一行作为表头；当前界面没有工作表选择功能。

### 行业与区域矩阵

“违约相关性矩阵计算器”和“相关性矩阵热力图生成器”使用带行列标签的矩阵表。第一行是列名，第一列是行名，其余单元格是数值，例如：

| 区域 | 华东 | 华北 |
| --- | --- | --- |
| 华东 | 1.00 | 0.35 |
| 华北 | 0.35 | 1.00 |

行业矩阵采用相同结构，将标签改为行业名称。行列标签应一一对应，数值范围为 `-1` 到 `1`，分类名称与企业信息表完全一致。

每次导入均读取第一张工作表。如果需要使用主计算导出的行业或区域矩阵，请将相应工作表分别另存为独立的 Excel 文件，保留行列标签。直接导入整个 `main_results.xlsx` 会读到排在第一张的企业矩阵。

### 加权矩阵用企业信息表

“违约相关性矩阵计算器”要求使用以下**精确列名**：

| 企业名 | 行业 | 区域 |
| --- | --- | --- |
| 企业A | 制造业 | 华东 |
| 企业B | 制造业 | 华北 |
| 企业C | 信息技术 | 华东 |

此处名称列是 **`企业名`**，与主计算表中的 **`企业名称`** 不同。不要添加额外的索引列，也不要省略行业或区域分类。

## 主计算操作

1. 进入“主计算”页，点击“加载 Excel”，选择准备好的价格表。
2. 如出现数据质量提示，先检查零值、缺失值和无穷大值。确认数据处理方式后继续；自动清洗的具体行为见下文。
3. 选择需要剔除的因子。“去市场因子”默认勾选，“去行业因子”和“去区域因子”默认不勾选。全部取消勾选时，直接对原始对数收益率计算相关性。
4. 设置窗口长度和步长，默认分别为 `60` 和 `10`。窗口长度至少为 `3`，步长至少为 `1`，两者均填写整数。
5. 点击“运行主计算”，等待进度窗口完成。
6. 在“显示”下拉框中切换企业、区域或行业相关性热图；在“视图”下拉框中查看对应的总体平均相关性时间曲线和年度统计。
7. 点击“导出结果”，选择保存位置，导出 Excel 工作簿。

界面中的窗口参数标为“天”，实际按收益率的**观测点数量**计算。例如，日频数据中的 60 期对应 60 个有效观测点；月频数据中的 60 期对应 60 个月度观测。曲线上的日期使用窗口中部的观测日期。

主计算使用 Pearson 相关系数。因子取当前样本中全部企业、同行业企业或同区域企业收益率的等权均值，其中包含被分析企业自身；剔除因子时，通过不含截距项的最小二乘回归计算残差。勾选哪些因子，就在回归中使用哪些因子。

### 主计算导出内容

| 工作表 | 内容 |
| --- | --- |
| 企业相关性 | 企业之间的相关性矩阵 |
| 区域相关性 | 按区域聚合的平均相关性矩阵 |
| 行业相关性 | 按行业聚合的平均相关性矩阵 |
| 区域总体平均_TS | 区域总体平均相关性的滑动序列 |
| 行业总体平均_TS | 行业总体平均相关性的滑动序列 |
| 企业平均总体_TS | 企业总体平均相关性的滑动序列 |
| 区域年度统计、行业年度统计、企业年度统计 | 相应滑动序列按年的均值、方差、最小值、最大值、中位数和四分位数 |
| 残差收益率_head | 残差收益率的前 500 行；未剔除因子时为原始对数收益率的前 500 行 |

没有可用滑动序列或年度统计时，对应工作表不会生成。残差收益率工作表最多包含前 500 行，不是完整收益率数据。

## 子集相关性分析操作

1. 先在“主计算”页加载数据并完成主计算。
2. 切换到“子集相关性分析”，选择一个或多个行业、区域，也可以使用“全选”。
3. 选择相关系数方法：Pearson、Spearman 或 Kendall。后两者为秩相关方法；方法定义见 [pandas 相关系数文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.corr.html)。
4. 如果需要观察时间变化，勾选“计算滑动总体平均相关性”，设置窗口长度和步长。
5. 点击“计算子集相关性”，查看矩阵热图、统计摘要及可选的时间曲线和年度统计。
6. 点击“导出结果”，保存子集分析工作簿。

筛选规则为：同一列表中的多个选项取并集，行业条件与区域条件同时满足才纳入子集。某个列表未选任何项时，该维度不作限制；两个列表都未选择时，使用全部企业。筛选后至少需要两家企业。

子集分析沿用主计算得到的收益率或残差收益率，不在子集内部重新计算因子或回归。若要更换因子设置，应先返回主计算页重新运行。

导出文件包含“子集相关性矩阵”和“子集统计”；计算出滑动序列时，还包含“子集总体平均_TS”。子集年度统计显示在界面中，当前不单独导出。

## 违约相关性矩阵计算器操作

1. 准备区域矩阵、行业矩阵和企业信息三个 Excel 文件，格式见前文。
2. 进入“违约相关性矩阵计算器”，依次点击“导入区域相关矩阵”“导入行业相关矩阵”“导入企业信息”。
3. 调整行业权重。行业权重与区域权重之和为 `1`，默认各为 `0.50`。
4. 调整整体缩放比例，范围为 `0.50` 至 `1.00`，默认 `1.00`。
5. 点击“计算违约相关性矩阵”，查看输出信息和热力图。
6. 点击“导出结果到Excel”，保存企业间矩阵。

当前界面实际执行的公式为：

```text
企业间矩阵值 = clip(缩放比例 × [行业权重 × 行业矩阵对应值
                            + 区域权重 × 区域矩阵对应值], 0, 1)
```

`clip` 表示将小于 `0` 的结果设为 `0`，大于 `1` 的结果设为 `1`。例如，行业对应值为 `0.40`、区域对应值为 `0.20`、两项权重各为 `0.50`、缩放比例为 `0.80`，最终结果为 `0.24`。

该模块构建的是按分类信息加权的企业间关联矩阵。当前界面流程没有输入企业违约概率或实际违约事件，也没有执行 Copula 参数估计。结果应按上述公式解释。

计算时，找不到的行业或区域标签对应项按 `0` 处理，可能不弹出错误。因此，应在导入前核对标签。输出不自动将对角线设为 `1`，也不自动执行对称化或正定性修复；缩放后对角线可能小于 `1`。

## 热力图生成器操作

1. 进入“相关性矩阵热力图生成器”，点击“导入Excel文件”，选择矩阵文件。
2. 点击 `-1`、`0`、`1` 对应的颜色按钮，自定义负相关、零相关与正相关的颜色。默认分别为蓝、白、红。
3. 点击“设置标题”，填写图表标题。
4. 根据需要选择“显示相关性系数数值”和“启用色彩过渡效果”。
5. 点击“生成热力图”。修改颜色、标题或显示选项后，再次点击该按钮更新图表。
6. 点击“保存热力图”，选择 PNG、JPEG 或 PDF 格式，保存 300 DPI 图表。

热力图的色标固定为 `-1` 至 `1`，数值标注保留两位小数。导入验证仅检查数值范围，不完整检查矩阵是否为方阵、是否对称或是否正定。

## 结果口径与当前版本限制

### 分组矩阵与平均相关性

区域和行业矩阵由所属企业之间的相关系数求平均得到，不是先合成区域或行业价格指数再计算相关性。同组单元格包含企业自身相关系数，因此分组矩阵的对角线通常不等于 `1`。

企业总体平均相关性及子集统计排除矩阵对角线。区域和行业的总体平均相关性则对各自聚合矩阵的非对角元素求平均，不按每组企业数量加权。年度统计汇总的是滑动窗口相关性序列。

### 自动清洗

自动清洗会移除全部缺失或全部为零的价格列，将零值与无穷大值替换为缺失值，再进行前向填充、后向填充及必要的列均值填充。

当前输入布局中，企业位于行、日期位于列；填充沿企业行方向执行，可能用其他企业同一日期的价格填补缺失，**并非沿单家企业的时间序列插值**。建议在导入前按各企业的时间序列完成数据清洗，并保留处理记录。

### 大文件与大样本

- 主计算导入超过 50 MB 的 Excel 时，会进入使用 `chunksize` 的读取分支；当前 [pandas.read_excel 接口](https://pandas.pydata.org/docs/reference/api/pandas.read_excel.html)不提供该参数，该分支会发生兼容性错误。修复前宜使用不超过该阈值的输入文件。
- 企业数超过 2000 时，主计算的企业相关性矩阵只返回首批最多 1000 家企业的结果，后续全样本分组矩阵也因此不完整。修复前，主计算的输入企业数应控制在 2000 家以内。
- 主计算在滑动窗口数量较多时会对窗口起点抽样，输出不一定覆盖原步长定义的全部窗口。进行连续时间分析时，应检查导出序列中的日期间隔。

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 启动提示缺少模块 | 确认依赖安装在启动程序所用的同一个 Python 环境中 |
| 读取 `.xls` 失败 | 安装 xlrd，或将文件另存为 `.xlsx` |
| 日期解析错误或趋势日期异常 | 使用 Excel 日期或 `YYYY-MM-DD` 表头，并按时间顺序排列日期列 |
| 只有矩阵，没有时间曲线 | 检查有效收益率观测数是否达到窗口长度，以及步长是否为正整数 |
| 提示子集企业不足 | 放宽行业或区域筛选条件，确保至少两家企业同时满足条件 |
| 相关系数出现空值 | 检查缺失价格、有效样本量、恒定收益率，以及剔除因子后是否仍有变化；单企业分组因子尤其容易造成残差缺乏变化 |
| 企业信息表列名不匹配 | 违约相关性矩阵计算器要求 `企业名`、`行业`、`区域` 三列 |
| 加权矩阵出现意外的零值 | 核对行业与区域矩阵标签，检查是否存在命名差异或负值被截断 |
| 保存 Excel 失败 | 关闭正在占用目标文件的 Excel 窗口，或改用新文件名 |
